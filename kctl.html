kctl

Home | Install | Install LTS

CLI tool to manage the system. Same on all images.

kctl upgrade                 # update system image, flatpaks and brew
kctl disable-update-notify   # turn off "out of date" notification
kctl help                    # show help

Update only one thing

rpm-ostree upgrade           # system image, reboot to apply
flatpak update               # flatpaks
brew update && brew upgrade  # brew
