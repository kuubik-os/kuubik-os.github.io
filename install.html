Images

  • kuubik: Fedora based, AMD/Intel GPUs
  • kuubik-nvidia: Fedora based, NVIDIA GPUs
  • kuubik-lts: AlmaLinux 10 based, AMD/Intel GPUs
  • kuubik-lts-nvidia: AlmaLinux 10 based, NVIDIA GPUs

ISO (recommended)

1) Download the netinstall ISO (checksum and signature) and write it to a USB drive.

2) Boot it and pick the image in the boot menu. It installs that image over the network, so it needs internet.

3) Works with secure boot on: on first reboot pick "Enroll MOK" and enter password kuubik. See Secure boot.

Rebase

1) Install Fedora Kinoite (for kuubik, kuubik-nvidia) or AlmaLinux Atomic Desktop KDE (for kuubik-lts, kuubik-lts-nvidia), then rebase to unsigned image. Replace kuubik with the image you want:

rpm-ostree rebase ostree-unverified-registry:ghcr.io/kuubik-os/kuubik

2) Reboot, then switch to signed image:

rpm-ostree rebase ostree-image-signed:docker://ghcr.io/kuubik-os/kuubik

3) For secure boot, enroll the key: see Secure boot.
