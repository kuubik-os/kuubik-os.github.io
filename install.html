Install from ISO

Download the netinstall ISO, boot it and pick kuubik (AMD/Intel GPUs) or kuubik-nvidia (NVIDIA GPUs) in the boot menu. It installs the image over the network, so it needs internet.

Verify it with the -CHECKSUM and .sig files from the same release:

sha256sum -c kuubik-netinstall-amd64.iso-CHECKSUM
cosign verify-blob --key https://raw.githubusercontent.com/kuubik-os/kuubik/main/cosign.pub \
  --signature kuubik-netinstall-amd64.iso.sig kuubik-netinstall-amd64.iso

Or rebase from Fedora Kinoite

For AMD/Intel GPUs:

1) Install Fedora Kinoite, then rebase to unsigned image:

rpm-ostree rebase ostree-unverified-registry:ghcr.io/kuubik-os/kuubik

2) Reboot, then switch to signed image:

rpm-ostree rebase ostree-image-signed:docker://ghcr.io/kuubik-os/kuubik

For NVIDIA:

1) Install Fedora Kinoite, then rebase to unsigned image:

rpm-ostree rebase ostree-unverified-registry:ghcr.io/kuubik-os/kuubik-nvidia

2) Reboot, then switch to signed image:

rpm-ostree rebase ostree-image-signed:docker://ghcr.io/kuubik-os/kuubik-nvidia

Secure boot

Kernel and NVIDIA driver are signed with the kuubik key, which has to be enrolled once:

  • ISO install: the key is queued during install. On first reboot pick "Enroll MOK" and enter password kuubik.
  • Rebase install: run kctl enroll-secure-boot-key, reboot, enroll, then enable secure boot.
