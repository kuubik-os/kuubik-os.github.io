Install kuubik LTS

Home | Install | kctl

For AMD/Intel GPUs:

1) Install AlmaLinux Atomic Desktop KDE, then rebase to unsigned image:

rpm-ostree rebase ostree-unverified-registry:ghcr.io/kuubik-os/kuubik-lts

2) Reboot, then switch to signed image:

rpm-ostree rebase ostree-image-signed:docker://ghcr.io/kuubik-os/kuubik-lts

For NVIDIA:

1) Install AlmaLinux Atomic Desktop KDE, then rebase to unsigned image:

rpm-ostree rebase ostree-unverified-registry:ghcr.io/kuubik-os/kuubik-lts-nvidia

2) Reboot, then switch to signed image:

rpm-ostree rebase ostree-image-signed:docker://ghcr.io/kuubik-os/kuubik-lts-nvidia

Secure boot is not supported for now.
