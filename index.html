kuubik

minimal atomic OS

Releases

  • kuubik: based on Fedora Kinoite, latest Fedora and CachyOS kernel. Install
  • kuubik LTS: based on AlmaLinux 10, with CachyOS LTS kernel. Slower moving, for those who want stable base. Install LTS

Both have -nvidia variant.

Features

  • CachyOS kernel instead of stock kernel. LTS uses CachyOS LTS kernel.
  • NVIDIA drivers (negativo17) in the kuubik-nvidia and kuubik-lts-nvidia images.
  • Multimedia codecs from RPM Fusion.
  • Less bloat: LibreOffice, Firefox, KDE games and other default apps removed. Install what you need from Flathub.
  • Flathub enabled out of the box.
  • Homebrew installed on first boot.
  • Extra packages: distrobox, tailscale (disabled by default. enable with `sudo systemctl enable --now tailscaled`).
  • Manual updates: no automatic background updates. You get a notification when system is more than month old.
  • kctl: CLI tool to manage the system.

Secure boot is not supported for now.
