kuubik OS

Features

  • CachyOS kernel instead of stock Fedora kernel.
  • NVIDIA drivers (negativo17) in the kuubik-nvidia image.
  • Multimedia codecs from RPM Fusion.
  • Less bloat: LibreOffice, Firefox, KDE games and other default apps removed. Install what you need from Flathub.
  • Flathub enabled out of the box.
  • Homebrew installed on first boot.
  • Extra packages: distrobox, tailscale (disabled by default.).
  • Manual updates: no automatic background updates. You get a notification when system is more than month old.
  • kctl: CLI tool to manage the system.

kctl

kctl upgrade                 # update system image, flatpaks and brew
kctl disable-update-notify   # turn off "out of date" notification
kctl help                    # show help

To update only one thing:

rpm-ostree upgrade           # system image, reboot to apply
flatpak update               # flatpaks
brew update && brew upgrade  # brew

Tailscale

Installed but disabled. Enable with:

sudo systemctl enable --now tailscaled

Install

For AMD/Intel GPUs:

1) Install Fedora Kinoite, then rebase to unsigned image:

rpm-ostree rebase ostree-unverified-registry:ghcr.io/kuubik-os/kuubik

2) Reboot, then switch to signed image:

rpm-ostree rebase ostree-image-signed:docker://ghcr.io/kuubik-os/kuubik

For NVIDIA:

1) Install Fedora Kinoite, then rebase to unsigned image:

rpm-ostree rebase ostree-unverified-registry:ghcr.io/kuubik-os/kuubik-nvidia

2) Reboot, then switch to signed image:

rpm-ostree rebase ostree-image-signed:docker://ghcr.io/kuubik-os/kuubik-nvidia

Secure boot is not supported for now.
